Registers are tiny, ultra-high-speed memory cells embedded directly inside the CPU core. Accessing RAM takes roughly 50 to 100 nanoseconds; reading a register takes less than a single nanosecond (a single clock cycle). Because memory is comparatively slow, machine execution happens almost exclusively inside CPU registers.

On x86_64 architectures, you have 16 general-purpose 64-bit registers: RAX, RBX, RCX, RDX, RSI, RDI, RBP, RSP, and R8 through R15.

Register Anatomy & The 32-bit Zero-Extension Trap

To preserve backward compatibility with 32-bit and 16-bit x86 software, x86_64 allows you to address sub-slices of the primary registers:

RegisterWidthBits CoveredHistorical / Primary Purpose
RAX64-bit[63:0]Accumulator, Function return values, Syscall numbers
EAX32-bit[31:0]Lower 32 bits of RAX (zero-extends upper 32 bits!)
AX16-bit[15:0]Lower 16 bits of RAX
AH / AL8-bit[15:8] / [7:0]High byte / Low byte of AX
RSP64-bit[63:0]Stack Pointer (always points to top of stack)
RBP64-bit[63:0]Base Frame Pointer (anchors the active function frame)
RIP64-bit[63:0]Instruction Pointer (address of next instruction to execute)
warning
The Golden Rule of x86_64 Zero Extension: Writing to an 8-bit or 16-bit sub-register (like AL or AX) leaves the rest of RAX unchanged. However, writing to any 32-bit register (like EAX) automatically clears all upper 32 bits of RAX to zeroes. Vulnerability researchers exploit this behavior to clear register clobbering when constructing shellcode and ROP chains!

Privilege Rings & The Syscall Boundary

CPUs enforce hardware isolation using Privilege Rings (typically Ring 0 and Ring 3):

lockRING 0Kernel / Supervisor
personRING 3Userland Binaries

Userland programs cannot execute privileged instructions (like disabling interrupts, altering CR3 page tables, or writing to physical ports). When a program wants to write to stdout or allocate memory, it executes the syscall instruction.

In x86_64 Linux, system calls pass arguments via registers:

  1. RAX: System Call Number (e.g., 59 for sys_execve, 1 for sys_write).
  2. RDI: 1st argument (e.g., pointer to filename string "/bin/sh").
  3. RSI: 2nd argument (e.g., argv pointer array).
  4. RDX: 3rd argument (e.g., envp pointer array).
