The call stack is the beating heart of procedural execution in C and assembly. It manages function parameters, local variables, frame nesting, and where execution must return when a function completes.

Two golden rules govern modern stacks on x86_64:

  1. LIFO (Last-In, First-Out): The most recent value pushed onto the stack is the first value popped off.
  2. Downward Growth: As values are pushed onto the stack, the Stack Pointer (RSP) decrements towards lower memory addresses. When values are popped, RSP increments towards higher addresses.

RSP points to 0x7fffffffe010. Pushing decreases RSP by 8 bytes; popping increases RSP by 8 bytes.

key
The Prologue and Epilogue Contract: Every standard compiled function opens with push rbp; mov rbp, rsp; sub rsp, N and concludes with leave; ret. The ret instruction is literally equivalent to pop rip: it takes whatever 8 bytes are at [RSP] and loads them directly into the CPU's instruction pointer!
